## Review procedure

For each sampled record, independently inspect the primary source and determine whether the Observatory's provenance chain is accurate and sufficiently documented.

Check:

- source institution identity;
- source URL and document availability;
- geography;
- reference period;
- published value;
- unit/measurement definition;
- transcription accuracy;
- transformation description, if any;
- comparability/structural-break note where applicable;
- retrieval and citation metadata.
